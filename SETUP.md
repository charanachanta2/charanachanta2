# Setup

This package is based on the supplied README design and has the portrait removed.

1. Create a GitHub profile repository named `charanachanta2`.
2. Copy these files into that repository.
3. Commit and push.
4. The included SVG files are the reference package's generated assets. Run/adapt
   `scripts/generate_stats.py` with your GitHub data to regenerate the statistics for `charanachanta2`.

The README itself already points to Charan's repositories.
